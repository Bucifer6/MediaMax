If your server takes requests, **Discover** in the sidebar lets you find titles that aren't in the library and ask for them. Approved requests are downloaded automatically and appear in the library when they're ready.

## Making a request

1. Open **Discover** and search, or browse the rows.
2. Open a title and choose **Request**.
3. For a show, pick **All seasons**, **First season**, **Latest season** or **Specific seasons**.
4. If you're allowed, tick **Also request in 4K** for a 4K copy.

You can follow everything you asked for under **My requests**.

## What the statuses mean

| Status | Meaning |
|---|---|
| **Pending** | Waiting for an admin (or a request manager) to approve it. |
| **Approved** | Accepted and sent to the download system. |
| **Processing** | Being downloaded or imported. |
| **Available** | In the library: press play. |
| **Declined** | Not accepted. The reason, if given, is shown on the request. |
| **Failed** | Something went wrong while sending or downloading it. An admin can retry it. |

Some accounts are approved automatically, so their requests skip *Pending*.

## Quotas

Your admin may limit how many requests you can make, for example 10 movies every 7 days. **Your request quota** on the Requests page shows what you have left. Requests made from a profile count towards the account owner's quota unless the admin gave the profile its own.

## Comments and the timeline

Each request has a timeline (requested, approved, downloading, available) and a **Comment** box for talking to whoever handles requests.

## I can't see Discover

Requests may be off on this server, or your account (or kids profile) isn't allowed to request that type of title.
