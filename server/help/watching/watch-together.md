**Watch together** keeps play, pause and seeking in sync for everyone in a room, wherever they are. Everyone needs their own account on this server (or a profile) and access to the title.

## Starting a room

1. Start the video.
2. Press the **Watch together** button in the player (the two-people icon).
3. Choose **Start a room**. A short code appears.
4. Send the code to your friends.

## Joining a room

- **In a browser**: open any video, press **Watch together**, type the code under **Room code** and choose **Join**.
- **In the phone or TV app**: **Settings → Join watch party**, then enter the code.

The room shows everyone who is in it; the person who started it is marked **Host**. When anyone pauses or seeks, everyone else follows.

## Leaving

Press **Watch together** and choose **Leave room**, or just close the player.

## Tips

- Each person streams from the server separately, so a slow connection only affects that person's quality.
- If your server admin has turned watch together off, the button doesn't appear.
