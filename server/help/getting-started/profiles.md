One account can hold several **profiles**, one per person. Each profile has its own watch progress, *Continue Watching*, *Next Up*, *My List*, ratings, recommendations, subtitle and audio settings, and theme.

## Adding a profile

1. Sign in as the account owner.
2. Open **Settings → Profiles** and choose **Add profile**.
3. Pick an avatar (or upload a picture), a colour and a name.
4. Optionally set a 4–8 digit **PIN**, a **maturity rating limit**, which libraries the profile can see, and its audio and subtitle language.

Your server admin decides how many profiles an account can have (6 by default).

## Who's watching?

Once an account has profiles, every device shows **Who's watching?** after signing in. Choose a tile (arrow keys or the remote's D-pad work on a TV). To change later, open the account menu and choose **Switch profile**. In the phone and TV apps it's **Settings → Switch profile**.

## PINs

A PIN stops other people in the house from opening your profile. Set or remove it under **Settings → Profiles** (or **Settings → Security → Profile PIN** for your own account). If you forget a profile's PIN, the account owner can change it.

## Kids profiles

Turn on **Kids profile** when adding or editing a profile. A kids profile:

- only shows titles up to its rating limit (PG unless changed), and hides titles with no rating;
- uses a simpler, playful theme;
- has no Discover page or requests, and no Live TV unless the admin allows it.

Leaving a kids profile for the owner's profile asks for the owner's PIN when one is set, so children can't switch back on their own.

## What profiles can't do

A profile never has more access than the account it belongs to. Profiles can't open the admin dashboard, change the account password or two-factor sign-in, create API keys, link devices or manage other profiles. Switch to the owner's profile for those.
