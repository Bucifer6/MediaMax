{{product}} is a private streaming service run on a server at home or in the cloud. Everything you watch or listen to comes from that server, not from a public streaming company.

## What you can do

- **Watch** movies, TV shows and home videos, picking up where you left off on any device.
- **Listen** to music, audiobooks and podcasts, or let the **DJ** mix songs for you.
- **Watch live TV** with a programme guide, and record shows if your server has recordings switched on.
- **Ask for new titles** from the **Discover** page, if your server takes requests.
- **Look at photos** in photo libraries.

What you see depends on how your server is set up. If a section is missing, the server admin has either not set it up or not given you access to it.

## Where to start

1. Pick your profile on the **Who's watching?** screen, if your account has profiles. See [Profiles, PINs and kids profiles](help:profiles).
2. Browse **Home**: rows such as *Continue Watching*, *Next Up* and *My List* are made for you.
3. Press **Play**. If something doesn't look or sound right, the [Troubleshooting](help:why-transcoding) articles explain what to try.

## Getting help

- Press <kbd>?</kbd> on a keyboard to see the keyboard shortcuts.
- The **?** buttons next to page titles open the matching help article.
- Your server admin can help with anything about your account or the library.
