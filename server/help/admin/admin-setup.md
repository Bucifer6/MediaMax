The first time you open a new server, the setup wizard asks for:

1. **Server name**: shown in every app. You can change it later in **Admin → Branding studio**.
2. **Create your admin account**: this account manages the server, users and branding. Use a strong password; administrators always need one.
3. **Add your first library**: a folder of movies, shows, music or photos (see [Libraries, scanning and folder naming](help:admin-libraries)).
4. **Live TV & IPTV**: optional; choose **Skip for now** if you don't need it.

## Next steps

| Do this | Where |
|---|---|
| Add a TMDB API key for posters, plots and cast (free for personal use) | **Admin → Server settings → General** |
| Set the **Public URL** if people will connect from outside | **Admin → Server settings → General** |
| Decide how people reach the server (direct, your own proxy, or built-in HTTPS) | **Admin → Network & HTTPS** ([guide](help:admin-network)) |
| Turn on hardware transcoding | **Admin → Server settings → Transcoding** ([guide](help:admin-transcoding)) |
| Invite family and friends | **Admin → Invites** ([guide](help:admin-users)) |
| Make it yours: logo, colours, home rows | **Admin → Branding studio** ([guide](help:admin-branding)) |
| Schedule backups | **Admin → Backups** ([guide](help:admin-backups)) |

## The admin dashboard

**Admin → Overview** shows who is watching now (with the playback method and why something transcodes), library counts, disk space and recent activity. Everything is also in **Admin → Activity & logs**.
