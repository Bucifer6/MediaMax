**Admin → Branding studio** controls what every app shows. Changes appear in the live preview and reach all connected apps straight away, without updating them.

| Tab | What you can change |
|---|---|
| **Starter looks** | One click sets a theme, home rows and features for a style: Home Cinema, Family & Kids, Music Lover, Live TV & IPTV, Minimal, Easy to See. Logos, text and your own themes are kept. |
| **Theme** | The default theme (24 built in, all meeting WCAG AA contrast), whether people may pick their own, and your own themes: colours, corner radius, font, poster shape, card size and hero style. |
| **Assets** | Logo, wide logo, favicon, app icon, splash screen, login background and TV images. |
| **Text** | Server name, tagline, login message, footer text and support link. |
| **Home rows** | Which rows Home shows and in what order: Continue watching, Next up, Top 10, Recommended, My List, Live now and more. |
| **Features** | Hide whole areas in every app: Live TV, IPTV, music, photos, downloads, watch together, recordings, the profile picker, link codes and requests. |
| **Custom CSS** | Fine-tune the web app's look. |

## The name in this Help Centre

Help articles use the server name you set here, so a white-labelled server never shows the original product name.

## Support link

If you set a support link in **Text**, it appears in the sidebar and in the apps' settings as a way for people to contact you.
