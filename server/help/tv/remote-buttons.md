These work with the TV's own remote, a soundbar or receiver remote over HDMI-CEC, and Bluetooth remotes.

## Playback buttons

| Button | Action |
|---|---|
| **Play / Pause** | Play or pause |
| **Stop** | Leave the player |
| **Fast-forward / Rewind** | Skip 10 seconds forward / back |
| **Next / Previous** | Next episode / back 30 seconds. In Live TV: next / previous channel |
| **Back** | Close a menu, leave the player, or go back |

## Colour buttons

| Button | Action |
|---|---|
| **Red** | Subtitles on / next language |
| **Green** | Next audio track |
| **Yellow** | Skip intro, credits or ad break (when the Skip button shows) |
| **Blue** | Info overlay. In Live TV: the channel list |

## Live TV buttons

| Button | Action |
|---|---|
| **Channel + / −** | Change channel |
| **0–9** | Type a channel number; it switches after a moment |
| **Guide** | Open the TV guide |
| **Info** | Show what's on and playback details |

In a video (not live TV), the number buttons jump to 0–90 % of the way through.

## By platform

| Platform | Notes |
|---|---|
| **Samsung (Tizen)** | All buttons work in the {{product}} TV app, which registers them with the TV. In the TV's web browser, some buttons may be kept by the TV. |
| **LG (webOS)** | All buttons work, including the colour buttons. |
| **Android TV, Google TV, Fire TV** | Media buttons, numbers and colour buttons (where the remote has them) work. Many Fire TV remotes have no colour or number buttons: use the on-screen menus instead. |
| **Apple TV** | Use the Siri Remote's touch surface to move, click to select, and the Back/Menu button to go back. |

**Info** and **Blue** show the playback details, including why a video is being converted. See [Why is it transcoding?](help:why-transcoding).
