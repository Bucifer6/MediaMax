## App review

On a dedicated review server, copy the three MP3s into a folder readable by Kinora. Add it under **Admin → Libraries → Add library**, select **Music**, then scan the folder. Give reviewers the server address and a working non-admin account in the store's private review notes. In the app, sign in, open the Music library, play Window Seat, seek in the track and add the other two tracks to the queue. Keep the review server available throughout review.
